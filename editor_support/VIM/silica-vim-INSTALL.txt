Silica Vim Syntax Highlighting
==============================

This archive adds syntax highlighting for Silica source files (*.silica).

Installation on macOS or Linux
------------------------------

1. Open Terminal and change to the directory containing silica-vim.zip.

2. Extract the archive into Vim's user configuration directory:

       mkdir -p ~/.vim
       unzip silica-vim.zip -d ~/.vim

   The archive should create these files:

       ~/.vim/syntax/silica.vim
       ~/.vim/ftdetect/silica.vim

3. Open ~/.vimrc. If it does not exist, create it:

       vi ~/.vimrc

4. Add these lines to ~/.vimrc:

       syntax on
       filetype plugin indent on

5. Start a new Vim session and open a Silica file:

       vi path/to/example.silica

The filetype should be detected automatically, and the active Vim colorscheme
will determine the actual colors.

If a Silica file is already open, restart Vim after installation. Alternatively,
run these commands inside Vim:

       :filetype on
       :syntax on
       :set ft=silica
