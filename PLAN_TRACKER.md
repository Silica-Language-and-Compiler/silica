# Plan tracker

## Instructions for LLMs (read this first)

This file is the **single list of all remaining work** from every development plan in this repository, ordered by
dependency. It is a tracker, not a plan: the detail (design, rationale, acceptance criteria) stays in each row's plan
file, linked on the row.

**When you complete a phase, chunk, stage, step or item that has a row here:**

1. **Mark it complete in its plan file** (the file linked in the row's "Plan" column), the way that file marks
   completed work (a status line, a stage-log entry, a "done" note with the date). The plan file is the record of
   what was done; do this first.
2. **Remove its row from this file.** Do not strike it through and do not leave a "done" row: a row here always means
   "not finished". Then fix the dependency order: any row that listed the removed ID in "Depends on" may now move to a
   lower "Order" section (or to Order 1) if all its other dependencies are also gone.
3. If finishing it changes what remains of the plan (a stage splits, a stage is dropped, a new dependency appears),
   update the plan file and then the affected rows here.

**When you add new work to a plan file**, add a row here in the right "Order" section with a unique ID, a link to the
plan file, and its dependencies. Do not add work that exists only here: every row must trace to a plan file.

**Do not** use this file to record results, measurements or status narrative; those go in the plan file or the
document it names. Keep each row to one line. Rows tagged `(inferred)` in "Depends on" have an ordering that was worked out when this tracker
was built, not stated in the plan; confirm it in the plan file when you start the row.

## How the order works

- **Order 1** rows have no unfinished dependency inside this tracker: they can be started now. Rows in the **same
  Order never depend on each other**, so any number of them can be done in parallel (subject to the build and trial
  machine limits in the build documentation).
- A row in **Order n** depends on at least one row in Order n-1 (and possibly earlier ones). Finish its dependencies first.
- **Depends on** lists tracker IDs. **Also waits on** lists dependencies that are not rows here: other repositories
  (for example Project BEES), hardware, or decisions that have to be made first. A row with an entry there cannot be
  finished until that is resolved, even in Order 1.
- State: `open`, `in progress` or `blocked`.
- This file was built on 2026-11-14 by reading every plan file listed in the last section. Some rows are marked "verify": the plan's text
  and the code or newer notes disagree, and the first job on such a row is to find out whether it is already done.

[ROADMAP.md](ROADMAP.md) remains the narrative of the emitter paths and chunk milestones; its chunks are rows here.
